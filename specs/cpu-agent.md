# SPEC — Windows Agent: CPU 측정 및 업로드

## 목표

Windows Agent가 실제 전체 CPU 사용률을 psutil로 측정해, 사용자가 입력한 6자리 연결 코드와 함께 현재 배포된 Vercel API(`https://pcproject-tau.vercel.app`)로 전송할 수 있다.

## 입력

- 사용자가 웹에서 발급받은 6자리 연결 코드를 Agent 실행 후 콘솔 프롬프트에 입력한다.

## 측정

- `psutil.cpu_percent(interval=...)`로 전체 CPU 사용률(%)을 측정한다.
- 2초 간격으로 반복 측정한다. (구현 시 조정 가능한 상수로 둔다.)

## 전송

- 매 측정마다 `POST {배포 URL}/api/data`를 호출한다.
- 요청 본문: `{"code": "<입력한 연결 코드>", "value": "<CPU 측정값을 담은 JSON 문자열>"}`
- `value`는 다음 내용을 JSON으로 직렬화한 문자열이다: `{"cpuPercent": <number>, "measuredAt": "<ISO8601>"}`
- 현재 `/api/data`는 `value`를 문자열로만 저장하므로 위 형식으로 맞춘다. API 자체는 이 슬라이스에서 수정하지 않는다.

## 사용자에게 보이는 결과 (Agent 콘솔)

- 연결 상태: 코드 입력 직후 `연결됨 (코드: XXXXXX)` 표시.
- CPU 측정값: 매 측정 주기마다 `CPU 사용률: NN.N%` 표시.
- 업로드 결과: 매 전송 시도마다 `업로드 성공` 또는 `업로드 실패: <사유>` 표시.

## 실패 조건

1. **잘못된 연결 코드** — Agent는 입력값이 정확히 6자리 영숫자 형식인지만 검증한다. 형식이 아니면 전송하지 않고 `잘못된 연결 코드 형식`을 표시한다.
   - 이번 슬라이스에서는 서버가 실제로 발급한 코드인지는 검증하지 않는다. (아래 '이번 슬라이스에서 만들지 않을 것' 참고)
2. **API 연결 실패** — 네트워크 오류, 타임아웃, HTTP 4xx/5xx 응답 시 `업로드 실패: API 연결 실패`를 표시하고 다음 주기에 다시 시도한다. 프로세스는 종료하지 않는다.
3. **CPU 측정 실패** — `psutil` 호출에서 예외가 발생하면 해당 주기의 측정을 건너뛰고 `CPU 측정 실패`를 표시한다. 프로세스는 종료하지 않고 다음 주기를 계속한다.

## 완료 조건 (눈으로 확인)

- Agent 실행 후 발급받은 코드를 입력하면 콘솔에 `연결됨` 상태가 표시된다.
- 2초 간격으로 콘솔에 실제 CPU 사용률 수치가 출력되고, 작업관리자 수치와 비슷한 범위임을 눈으로 비교할 수 있다.
- 같은 연결 코드로 `GET /api/data?code=...`를 호출하면 방금 전송한 CPU 측정값 JSON 문자열이 그대로 조회된다.
- 코드를 5자리로 입력하면 `잘못된 연결 코드 형식`이, 네트워크를 끊으면 `업로드 실패: API 연결 실패`가 콘솔에 표시된다.

## 이번 슬라이스에서 만들지 않을 것

- 실제 발급 코드 유효성 검증 (서버가 발급한 코드인지 확인. 형식 검증까지만 한다.)
- CPU 90% 이상 5초 지속 판별 로직
- 관련 프로세스 분석
- [지금 느려요] 분석 기능
- PyInstaller exe 패키징
- RAM / Disk 분석
