# SPEC — 웹: 연결 코드로 CPU 측정값 조회 및 표시

## 목표

사용자가 웹 화면에서 연결 코드를 입력하면, 해당 코드로 Windows Agent가
업로드한 최신 CPU 측정값을 조회해 화면에 표시할 수 있다.

## 입력

- 사용자가 웹 화면의 입력창에 6자리 연결 코드를 입력한다.
- "조회" 버튼을 클릭하면 기존 API `GET /api/data?code=<입력한 코드>`를
  호출한다. API 자체는 이 슬라이스에서 수정하지 않는다.

## 조회 및 표시 로직

- 응답의 `value`가 `null`이면 아직 수신된 데이터가 없는 상태로
  표시한다.
- `value`가 문자열이면 JSON으로 파싱을 시도한다.
  - 파싱에 성공하고 `cpuPercent`(number)와 `measuredAt`(string) 필드가
    모두 있으면: 데이터 수신됨 상태로 전환하고 CPU 사용률과 측정
    시각을 표시한다.
  - 파싱에 실패하거나 필드가 없으면 데이터 형식 오류 상태로 표시한다.
    없는 수치를 추정해서 보여주지 않는다.

## 사용자에게 보이는 결과 (웹 화면)

1. **Agent 연결 / 데이터 수신 여부** — 다음 세 상태 중 하나를 문구로
   표시한다.
   - `아직 수신된 데이터 없음`
   - `데이터 수신됨`
   - `데이터 형식을 확인할 수 없음`
2. **최신 CPU 사용률(%)** — 데이터 수신됨 상태일 때만 표시한다. 예:
   `CPU 사용률: 42.3%`
3. **마지막 측정 시각** — 데이터 수신됨 상태일 때만 표시한다.
   `measuredAt`(ISO8601)을 사용자 로컬 시간대 문자열로 변환해 표시한다.
   예: `마지막 측정: 2026-08-27 14:32:10`

## 실패 조건

1. **잘못된 연결 코드 형식** — 입력값이 정확히 6자리 영숫자가 아니면
   조회 요청을 보내지 않고 `잘못된 연결 코드 형식`을 표시한다.
2. **데이터 없음** — API가 `value: null`을 반환하면 오류가 아닌
   `아직 수신된 데이터 없음` 상태로 표시한다.
3. **API 요청 실패** — 네트워크 오류 또는 HTTP 오류 응답 시
   `조회 실패`를 표시한다.
4. **데이터 형식 오류** — `value`가 JSON 파싱에 실패하거나
   `cpuPercent` / `measuredAt` 필드가 없으면
   `데이터 형식을 확인할 수 없음`을 표시하고, 없는 수치를 추정해
   보여주지 않는다.

## 완료 조건 (눈으로 확인)

- 실제 Windows Agent(`agent/cpu_agent.py`)를 실행해 연결 코드를
  입력하고 업로드를 시작한다.
- 웹 화면에서 같은 연결 코드를 입력해 조회하면, Agent가 방금 측정한
  CPU 사용률(%)과 측정 시각이 화면에 표시되고, 작업관리자 수치와 비슷한
  범위임을 눈으로 비교할 수 있다.
- Agent가 아직 연결되지 않은, 형식은 올바른 임의의 코드로 조회하면
  `아직 수신된 데이터 없음`이 표시된다.
- 6자리가 아닌 값을 입력하고 조회를 시도하면 `잘못된 연결 코드 형식`이
  표시된다.
